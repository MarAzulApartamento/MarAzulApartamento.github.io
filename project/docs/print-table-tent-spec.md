# Table flip stand — print spec

**Last updated:** 2026-05-14
**Status:** drafted for Stefania's review. Replaces both the original A5 table tent and the standalone welcome card (item #25 + item #8 in `questions-for-stefania.md`, merged 2026-05-14).
**Goal:** sit on the dining table for the entire stay. Answer most "what / how / who" questions a guest has in their first hour, then keep working as a quiet reminder for the rest of the stay — house rules, emergency contacts, SUP rental, and a calm Google-review nudge near the end.

This is the **centrepiece** of the in-apartment print set. Everything else (fridge magnet, apartment guide folder) revolves around it.

---

## What this is

A vertical desk flip stand — same product family as `https://www.joom.com/pt/products/69c501704ea9ac017df807d7`. Eight content panels per side, two sides (one Portuguese, one English). One stand per apartment. The guest turns it around 180° to switch language. The flip pages let the stand hold more content than a static tent without overwhelming any one page.

---

## Format

| Spec | Value |
|---|---|
| Format | Vertical desk flip stand, multi-page flip pad mounted on a stand base |
| Panels per side | **8** content panels |
| Languages per stand | **2** — Portuguese on one side, English on the other (180° rotation switches language) |
| Quantity | **1 stand per apartment** |
| Paper | Thick card stock (~300-350 gsm), uncoated or lightly coated. Uncoated reads warmer; lightly coated wipes clean if a guest spills coffee. Decision in section below. |
| Print | Full colour CMYK, double-sided per page so EN/PT mirror cleanly |
| Brand tokens | Atlantic Blue (#1E5B73), Warm White (#FAFAF7), Deep Navy (#1d2630), Seafoam (#A8CFC6), Sun Sand (#E6D8B7). Spectral display, Manrope body. |

## Open decisions for Stefania

1. **Paper finish** — uncoated (warmer, more "letter from the host", but stains if a guest spills) or lightly coated (wipeable, slightly cooler feel)? **Recommendation: lightly coated** because this stand sits on the dining table for the entire stay and will see coffee and oil. The warmth comes from typography and palette, not from paper texture.
2. **Photos on panels** — should Panel 7 (SUP) include a photo of the board? Photos make it more concrete and inviting, but require the photo to be high-resolution and not awkwardly cropped at flip-page size. **Recommendation: yes**, if there's a clean board photo. Pending Stefania uploading one to `assets/images/apartment-guide/sup/`.
3. **Confirm "Apartment Guide Folder" wording** — or shorter alternative like "Apartment Guide" / "Mar Azul Guide" / "Apartamento Mar Azul Guide". **Recommendation: "Apartment Guide" (without "Folder")** for brevity on panel 8.
4. **Three restaurants or two?** — Os Lambertos and O Prato Cheio are confirmed. Add a third? **Recommendation: two for the flip stand** (keeps Panel 4 calm); fuller restaurant list lives in the Apartment Guide Folder.
5. **Print vendor** — local Lagos shop (fastest, cleanest for in-person proof) or online (Vistaprint / specialised flip-stand printer; cheaper for re-orders)? **Recommendation: local Lagos shop for the first run** so we can hold a physical proof before the bulk print.
6. **Quantity** — 1 flip stand for the apartment. Plus 1 spare on the shelf for when the first one gets damaged? **Recommendation: print 2, store the spare.**
7. **GBP review QR target** — confirm the exact GBP review URL once GBP is fully set up.
